## Goal
Snapshot the current project state so the next session picks up instantly.

## Steps
1. Read `tasks/todo.md` — get current plan and progress
2. Summarise the current state:
   - What's been completed
   - What's in progress
   - What's blocked and why
   - Key file paths, decisions made, gotchas
3. Write to `tasks/memory.md` — overwrite with latest snapshot
4. Confirm it was saved

## Rules
- Be specific — vague summaries are useless
- Include file paths and function names where relevant
- Keep it under 300 words
